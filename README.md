### Canary Mail setup

Canary Mail is an email client. Add the accounts above so GitHub notifications and support mail appear in one place:

1. Open Canary Mail → Settings → Accounts → Add Account.
2. Choose **Gmail** and sign in with:
   - `chrisemerson360agency@gmail.com` (Agent Chris Emerson — also receives support@)
   - `alonejamesowns@gmail.com`
   - `pointgoddesscc@gmail.com`
3. Grant full mail and contacts permissions when prompted.
4. Name each account clearly (e.g. "Chris Emerson", "Alone James", "Point Goddess").
5. Enable notifications for the Chris Emerson account so support@ alerts appear.

GitHub notifications sent to `pointgoddesscc@gmail.com` will show in Canary Mail once that account is added.
