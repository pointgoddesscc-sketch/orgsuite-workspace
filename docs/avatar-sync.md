## Sync procedure (run whenever the image changes)

1. **Save the master file** offline (PNG or JPG, square, at least 400×400).
2. **Gravatar first** (helps many sites that use email avatars):  
   - https://gravatar.com → sign in with `pointgoddesscc@gmail.com` → upload → set primary
3. **GitHub:** Settings → Profile → upload same file  
   https://github.com/settings/profile
4. **GitLab:** Preferences → Profile → Avatar  
   https://gitlab.com/-/profile
5. **X:** Profile → Edit profile → photo  
   https://x.com/settings/profile
6. **Meta:** Page / profile picture for the accounts used with Meta AI
7. **Optional:** ChatGPT account profile photo

Tick the matrix above after each update.
