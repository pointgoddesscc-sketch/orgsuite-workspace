# Working Copy – Clone & Use This Workspace

## One-time clone

1. Open **Working Copy** on iPhone.
2. Tap **+** → **Clone repository**.
3. Paste this exact URL:

```
https://github.com/pointgoddesscc-sketch/orgsuite-workspace.git
```

4. Authenticate with the GitHub account that owns `pointgoddesscc-sketch`.
5. Open the repository.

You now have the clean professional OrgSuite Workspace.

## Daily use

- Before editing: **Pull**
- After editing: Commit → Push (prefer a branch + Pull Request)
- After any merge on GitHub: **Pull** again
